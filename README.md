# Iris

A liquid-glass color picker for macOS. Click the menu bar icon, hover anywhere on screen, click to copy the HEX value.

- Glass magnifier lens with scroll-to-zoom (1×–16×)
- Pixel-exact picking at high zoom
- Lens look adjustable in **Lens Settings…** (right-click the menu bar icon)
- Start at login, automatic updates

## Download

**[Download the latest Iris](https://github.com/danielbalazs/iris/releases/latest/download/Iris.zip)** — macOS 14 or later, Apple Silicon and Intel.

First launch: Iris isn't notarized yet, so right-click `Iris.app` → **Open** → **Open**. Then allow **Screen & System Audio Recording** for Iris when macOS asks, and reopen it once.

This repository hosts releases and the update feed (`appcast.xml`) used by the app's built-in updater.
